# data/temp — 中间数据

存放程序运行过程中产生的**中间数据**：缓存、分片、中间表、临时导出。

**这里的文件 100% 可重建**，随时可以清空，不承担任何长期价值。

## 与 `temp_text/` 的区别

| 目录 | 内容 | 读者 |
| --- | --- | --- |
| `data/temp/` | 程序中间数据：JSON、CSV、缓存、分片 | 程序 |
| `temp_text/` | 网页正文、OCR 结果、人工草稿 | 人 |

## 写入规则

- 文件名带上**会话 ID 或日期**，避免并行任务互相覆盖：`<会话ID>-<步骤名>.json`
- 一个任务一个子目录更稳妥：`data/temp/<会话ID>/`
- 中间结果**不得**成为唯一副本：凡是有后续依赖的，必须能由 `data/core/` 重跑得到

## 清理

- 任务验收后，由执行者清理自己产生的中间数据（只删自己建的）
- 超过 7 天的内容视为可清理
- 清理**按文件或按自己的子目录**进行，严禁批量删除整个目录、严禁跨任务删除

## 红线

- 不放正式输入（属于 `data/core/`）
- 不放交付产物（属于 `output/`）
- 不放密钥、token、个人信息
- 不把「只存在于这里、丢了就没了」的东西放这里
